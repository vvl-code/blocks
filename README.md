# My Games — бесплатные игры в Telegram и на iPhone

Статический игровой каталог без рекламы, платных API, аналитики или собственного сервера.

## Играть

- **My Games (каталог):** https://vvl-code.github.io/blocks/catalog/
- **Блоки:** https://vvl-code.github.io/blocks/
- **Три в ряд:** https://vvl-code.github.io/blocks/match3/
- **Косынка:** https://vvl-code.github.io/blocks/solitaire/

Telegram-бот: https://t.me/vvl_my_games_bot — его кнопка «Каталог» открывает My Games. Игра встраивается в Telegram Mini App через iframe. Возврат в каталог работает через «Игры» или BackButton Telegram без повторного нажатия.

## Совместимость

**Блоки** по-прежнему публикуются в корне репозитория и доступны как самостоятельная PWA на iPhone. Установленные иконки переустанавливать не нужно; кеш Service Worker обновляется при запуске онлайн. Для установленной игры офлайн-режим сохраняется. Новые игры на /match3/ и /solitaire/ доступны онлайн через каталог (отдельный офлайн-кеш для них пока не предусмотрен).

На компьютере игры работают с мышью, на iPhone — касаниями и жестами. Данные хранятся локально в браузере/WebView; **рекорды не синхронизируются между устройствами** и могут исчезнуть после очистки данных сайта.

## Правила

- **Блоки:** поле 10×20, семь фигур, очки, уровни, пауза и сохранение партии.
- **Три в ряд:** поле 8×8, обмен соседних кристаллов, каскады, 30 ходов, прогресс уровня, сохранение партии и рекорда.
- **Косынка:** стандартные 52 карты, 7 столбцов, раздача по одной карте, повторный проход колоды, 4 домика, перенос открытых последовательностей, отмена и подсказки; автосохранение расклада и локальный счётчик побед.

## Архитектура

Без сборщика и backend: HTML/CSS/JavaScript ES modules.

- / — «Блоки» и Service Worker для установленной PWA.
- /catalog/ — интерфейс My Games, маршрутизатор игр, Telegram WebApp BackButton.
- /match3/engine.js — правила «Три в ряд», /match3/app.js — сенсорный интерфейс.
- /solitaire/engine.js — правила «Косынки», /solitaire/app.js — карточный интерфейс.
- /tests/ — автоматические тесты движков (Node.js >=20, без npm-зависимостей).

Тестирование: npm test. GitHub Actions запускает тесты на обновлениях ветки main.

Публикация: GitHub Pages → Settings → Pages → Deploy from a branch → main → /(root).

Название и оформление **не связаны с правообладателем Tetris или Microsoft**.
