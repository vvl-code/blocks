# Блоки — классическая игра для iPhone

Бесплатная PWA-игра с падающими фигурами: поле 10×20, семь тетромино, уровни, очки, рекорд, пауза и сохранение партии. Без рекламы, регистрации, аналитики, платных библиотек и собственного сервера.

## Запуск на iPhone

Адрес после включения GitHub Pages: https://vvl-code.github.io/blocks/

В Safari откройте сайт, нажмите «Поделиться» → «На экран Домой» → «Добавить». Затем запускайте игру с иконки «Блоки». Первый запуск требует интернета, после загрузки Service Worker игра работает офлайн.

## Включение GitHub Pages

В репозитории **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**. Подождите завершения публикации и откройте адрес выше.

## Технологии

Vanilla JavaScript ES modules, Canvas, CSS, Service Worker. Серверная логика отсутствует. Игра не связана с владельцем торговой марки Tetris.

Управление: сенсорные кнопки или жесты по полю, на ПК — стрелки и пробел. Лучшие результаты хранятся локально в браузере.

Содержимое проекта основано на версии 1.1 игры. Исходный движок разделён с браузерным интерфейсом, тесты доступны в исходном ZIP-архиве версии 1.1.
